# TS9Designs Website

Website for TS9Designs, a Building Design company providing MEP (mechanical, electrical,
plumbing), structural, and fire design services for residential and commercial projects.

Live at [ts9designs.com](https://www.ts9designs.com).

## Structure

- Root `.html` files — main pages (home, about, services, pricing estimate, contact, etc.)
- `case-studies/` — write-ups of completed projects
- `assets/` — images, CSS, JS, email templates, and the source drawing-set PDFs
- `vendor/` — Bootstrap and jQuery

No build step — it's plain HTML/CSS/JS, hosted on GitHub Pages.
